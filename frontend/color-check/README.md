# color-check（仮配色チェック）

サイトの配色を決めるための検討用プレビューです。素の HTML/CSS/JS だけで動き、ビルドも依存パッケージもありません。

**アプリ本体の実装ではありません。** frontend の技術選定（[`../README.md`](../README.md)）とは切り離した、色を見るためだけの使い捨てページです。

## 確認のしかた

### 1. 共有リンクで見る（セットアップ不要）

https://claude.ai/code/artifact/76c914f8-a309-42f8-851e-d7617bc489b2

1ファイルにまとめたものを公開しています。スマホからも開けます。
リンクは既定で非公開なので、共有相手はページの共有メニューから設定してください。

### 2. ローカルで開く

`index.html` をブラウザにドラッグするだけで動きます。ローカルサーバー経由で見る場合は次のいずれかで。

```bash
cd frontend/color-check
python -m http.server 8080   # → http://localhost:8080
```

## 触れるところ

| 操作 | 内容 |
| --- | --- |
| 標準表示 / 園児装飾 | 落ち着いた通常表示と、クレヨン線・破線・影を強めた園児UIの切り替え |
| 赤ちゃん / お母さん | ペルソナごとの縁取り色の切り替え（[design_doc §3.2](../../docs/design_doc.md) の2ペルソナ） |
| ベース / アソート / アクセント | 3色をカラーピッカーまたは HEX 直接入力で差し替え |
| プリセット | 検討中の配色案。押すと3色まとめて反映 |
| Contrast | 選んだ色の WCAG コントラスト比。本文は 4.5:1 以上が目安 |

## 見てほしい観点

- 標準表示を既定にして、長時間見ても疲れないか
- 園児UI用の3色が、名札・スタンプ・空状態に使いやすいか
- 臙脂が強すぎず、でも押したくなるか
- 子どもの絵がブランド素材として浮かずに馴染むか

配色案そのものへの意見は Issue（`type:discussion`）にお願いします。

## 共有リンクを更新する

プリセットや画面を直したあと、同じリンクに反映する手順です。

```bash
cd frontend/color-check
python build_artifact.py   # → dist/engiiro-color-lab.html
```

生成された `dist/engiiro-color-lab.html` を、既存の Artifact と同じ URL に再公開します（`dist/` は gitignore 済み）。

# 学習データの正本(唯一の置き場)

`ai/src/style_classifier.py`(赤ちゃん/お母さん/その他の3クラス判定、`POST /api/ai/evaluate`の
`passesThreshold`に使用)の学習データ。**このディレクトリが唯一の正本**であり、
今後の学習データの追加・修正はここへ直接行う。

## 背景(2026-08-27統合)

学習データが2箇所に分かれて別々に育っていた。

- `engiiro/naive-bayes-sample`(教育用サンプルリポジトリ)側でメンバーがPRを送り、
  `gen_round1〜11`を蓄積(11,525件、赤ちゃん3,855/お母さん3,869/その他3,801)。
- 一方、engiiro-appリポジトリ側でも別のメンバーが`ai/naive_bayes_sample/data/`へ
  独自にPRを送り、上記に加えて`review_batch01〜15`・`sheet_3000`(Googleスプレッドシート
  由来3,000件)・`moderation_examples`を追加(合計15,055件)。

このまま放置すると同じ目的のデータが2つのリポジトリ・2つのPR系統でバラバラに
育ち続けてしまうため、両方の内容を突き合わせて1箇所へ統合した。

## 統合内容

- 統合元: engiiro-app `ai/codex/evaluate-baseline`ブランチ(PR #53)の
  `ai/naive_bayes_sample/data/`(`naive-bayes-sample`のPR #1のデータを内包した上位互換)
- 重複除去: NFKC正規化+ゼロ幅文字除去+空白除去+記号除去で正規化した文字列が
  完全一致するものを重複とみなして除去(`naive-bayes-sample`の
  `app/dataset_quality.py`と同じロジック)。**実際の重複は0件**だった
  (クラスをまたいだ表記ゆれ重複も含めて0件)。
- 統合後の件数: 赤ちゃん5,105 / お母さん5,119 / その他4,831(合計15,055、比率ほぼ1:1:1)

## 今後の運用

- 学習データを追加・修正する場合は、**このディレクトリに直接JSONファイルを追加する**
  (1ファイル=文字列の配列)。`naive-bayes-sample`リポジトリや他のブランチへ
  別々に追加しない。
- `naive-bayes-sample`リポジトリは教育用サンプルとして引き続き独立して存在するが、
  本番の分類器が使う学習データの正本ではなくなった。

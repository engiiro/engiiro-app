# NG辞書

`ai/moderation_rules.py` が読み込む辞書です。

Gemini API が使えないときの二次判定として、**この辞書だけで動く**ことを
前提にしています。形態素解析（janome）はローカルで動くので、
ここに語を足せば足しただけ、通信なしで判定できる範囲が広がります。

## 書き方

1行1語。空行と `#` で始まる行は無視します。

```
語<TAB>照合方法
```

照合方法を省いた場合は `substring` になります。

| 照合方法 | 意味 | 使いどころ |
|---|---|---|
| `substring` | 正規化した文字列への部分一致 | 他の語の一部にならない語。漢字表記など |
| `token` | 形態素解析して1語として一致 | ひらがな表記など、他の語に埋もれる語 |
| `名詞` | 上に加えて品詞も一致 | 罵倒にも日常語にもなる語 |

## どれを選ぶか

**まず `substring` を試して、日常語に当たるようなら `token` か品詞指定にしてください。**

実例です。

| 語 | 照合方法 | 理由 |
|---|---|---|
| `死ね` | `substring` | 他の語に埋もれない |
| `しね` | `token` | 「推しねこ」に当たる |
| `ころす` | `token` | 「石ころすら」に当たる |
| `がいじ` | `token` | 「これが以上」に当たる |
| `バカ` | `名詞` | 「ばかり」は助詞なので除ける |
| `クズ` | `名詞` | 「くずれる」は動詞なので除ける |

## 入れてはいけない語

**日常語と品詞でも文脈でも区別できない語は入れないでください。**
規則で無理に拾うと、普通に使っている人が弾かれます。

| 語 | なぜ入れないか |
|---|---|
| `ゴミ` | 罵倒も「ごみを捨てる」も名詞。分けられない |
| `アホ` | 「アホらしい」が「バカだ」と同じ形になる |
| `死ぬ` | 「サーバーが死んだ」を巻き込む |
| `刺す` | 「釘を刺す」を巻き込む |
| `殴る` | 「壁を殴る」を巻き込む |

この種のものは、Gemini 側の文脈判定に任せます。

## 語を足したら

`ai/tests/patterns.py` に、その語を使った文と、
**似ているが弾いてはいけない日常語**の両方を足してください。

```bash
python -m pytest ai/tests/test_patterns.py -q
```

弾いてはいけないものを弾かないことのほうが大事です。
えんじいろの利用者はエンジニアなので、技術用語や日常語が弾かれると
サービスとして使えなくなります。

## ファイル

| ファイル | 判定 |
|---|---|
| `block.txt` | どう言い換えても前向きにならない語 |
| `rewrite.txt` | 言い換えれば愚痴や励ましになる語 |
| `self_harm.txt` | 自傷。人間監督の決定により例外なく block |
| `harm_others.txt` | 他害・犯罪示唆。同上 |

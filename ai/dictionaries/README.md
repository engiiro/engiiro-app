# NG辞書

`ai/moderation_rules.py` が読み込む辞書です。

**判定APIはこの辞書と形態素解析だけで動きます。通信しません。**
二次判定ではなく、これが判定のすべてです。
ここに語を足せば足しただけ、弾ける範囲が広がります。
逆に言うと、**辞書に無い語は誰も拾ってくれません。**

## 書き方

1行1語。空行と `#` で始まる行は無視します。

```
語<TAB>照合方法
```

照合方法を省いた場合は `substring` になります。

| 照合方法 | 意味 | 使いどころ |
|---|---|---|
| `substring` | 正規化した文字列への部分一致 | 他の語の一部にならない語。漢字表記など |
| `token` | 形態素解析して1語として一致 | ひらがな表記など、他の語に埋もれる語 |
| `名詞` | 上に加えて品詞も一致 | 罵倒にも日常語にもなる語 |

## どれを選ぶか

**まず `substring` を試して、日常語に当たるようなら `token` か品詞指定にしてください。**

実例です。

| 語 | 照合方法 | 理由 |
|---|---|---|
| `死ね` | `substring` | 他の語に埋もれない |
| `しね` | `token` | 「推しねこ」に当たる |
| `ころす` | `token` | 「石ころすら」に当たる |
| `がいじ` | `token` | 「これが以上」に当たる |
| `バカ` | `名詞` | 「ばかり」は助詞なので除ける |
| `クズ` | `名詞` | 「くずれる」は動詞なので除ける |

## 入れてはいけない語

**日常語と品詞でも文脈でも区別できない語は入れないでください。**
規則で無理に拾うと、普通に使っている人が弾かれます。

| 語 | なぜ入れないか |
|---|---|
| `ゴミ` | 罵倒も「ごみを捨てる」も名詞。分けられない |
| `アホ` | 「アホらしい」が「バカだ」と同じ形になる |
| `死ぬ` | 「サーバーが死んだ」を巻き込む |
| `刺す` | 「釘を刺す」を巻き込む |
| `殴る` | 「壁を殴る」を巻き込む |

**この種のものは、素通りします。** 判定APIにLLMはいません。
それでも入れないでください。弾いてはいけない文を弾くほうが害が大きいためです。

## 候補を機械的に探す

語を人手で思いつくのは大変なので、手元のLLMに探させる道具があります。

```bash
ollama pull qwen3:4b
python ai/dictionaries/harvest.py --file candidates.txt
```

投稿候補の文を流すと、辞書へ入れられそうな語を出します。
上の「入れてはいけない語」と、通すべき文を弾く語は自動で捨てます。

次の2つは、**貼れない形（行頭に `#`）で保留として出します。**

| 保留になるもの | なぜ |
|---|---|
| 普通の使い方が見つかった語 | 入れると日常語を巻き込む。例文をつけて出します |
| どの辞書か決まらなかった語 | 上の4ファイルのどれでもない、または複数にまたがる |

後者が起きるのは、個人情報（`personal_data`）や性的表現に
**対応する辞書が無い**ためです。個人情報は辞書ではなく規則で見ています。
決められないものを `rewrite.txt` へ入れると、その語は本番でマサカリ扱いになり、
**弾いたあと利用者へ見せる文言まで変わってしまいます。**

**手元で動くので、外部APIの利用回数を気にせず何万件でも流せます。**
GPUが無いと1件5〜6秒かかるので、流しっぱなしにして待つ使い方になります。

**本文は手元にしか送りません。** 接続先は環境変数で変えられますが、
手元以外へ向けた場合は `ENGIIRO_LOCAL_LLM_ALLOW_REMOTE=1` を置かないと動きません。
投稿候補には個人情報が混じり得るためです。

出てくるのは候補です。**そのまま貼らず、3列目の根拠を確かめてください。**

## 語を足したら

`ai/tests/patterns.py` に、その語を使った文と、
**似ているが弾いてはいけない日常語**の両方を足してください。

```bash
python -m pytest ai/tests/test_patterns.py -q
```

弾いてはいけないものを弾かないことのほうが大事です。
えんじいろの利用者はエンジニアなので、技術用語や日常語が弾かれると
サービスとして使えなくなります。

## 他のAIへ依頼するとき

相手が読める形式のものを渡してください。中身は3つとも同じです。

| ファイル | 渡す相手 |
|---|---|
| `AI_TASK.md` | Markdown を読めるもの（ChatGPT、Gemini、Claude など） |
| `AI_TASK.txt` | Markdown を扱えないもの |
| `ai_task.py` | GitHub Copilot など、コードを文脈にするもの。書き込み欄つき |

`.txt` と `.py` は `AI_TASK.md` から生成しています。
**直すときは `AI_TASK.md` だけを直して、生成し直してください。**

```bash
python ai/dictionaries/build_formats.py
```

## ファイル

**4つとも block です。** 分かれているのは理由コードを分けるためで、
弾いたあと利用者へ何を見せるかが変わります（自傷なら相談窓口を出す、など）。

| ファイル | 何を入れるか | 理由コード |
|---|---|---|
| `block.txt` | 露骨な侮辱語・差別語 | `ng_word` |
| `rewrite.txt` | 他人を責める、能力や人格を否定する語（マサカリ） | `harsh_criticism` |
| `self_harm.txt` | 自傷を示す語 | `self_harm` |
| `harm_others.txt` | 他害・犯罪をほのめかす語 | `harm_others` |

`rewrite.txt` というファイル名は、以前の方針（言い換えを促す）の名残です。
人間監督の決定により「マサカリは完全にブロック。状況によって変えない」へ変わりました。
**中身はマサカリ語で、当たれば block になります。**

## 辞書がすべてを決める

**判定APIは、この辞書と形態素解析だけで動きます。通信しません。**
人間監督の決定により、判定はAPI制限を消費しません。
つまり**辞書に無い語は弾かれません。** ここを育てることが判定の質そのものです。

外部モデレーションAPIと Gemini は、判定APIでは使いません。
`transform_api.moderate_by_llm()` として分けてあり、
**辞書へ入れる語を探すための道具**という位置づけです。

**辞書に無い語を外部APIが拾うこともあります。** ただし外部APIは、
えんじいろ固有の事情（技術用語を弾いてはいけない、弱音は通す）を知りません。
辞書を育てる価値は変わりません。

外部APIの設定は `ai/external_moderation.py` の冒頭を読んでください。

### 使えるサービス

| サービス | 得意 | 実測 |
|---|---|---|
| chakoshi（NTT） | **日本語のニュアンス**。カテゴリを自分で選べる | 確認済み |
| Google Cloud Natural Language | 侮辱・差別的表現 | 確認済み |
| Azure AI Content Safety | 自傷の専用カテゴリがある | 未確認（キー未取得） |
| OpenAI Moderation | 自傷・暴力・嫌がらせ | 未確認（429で呼べず） |

料金と無料枠は各社の都合で変わるので、ここには書きません。
必要な環境変数は `ai/external_moderation.py` の冒頭にあります。

**Google は自傷の検出に向きません。** 返ってくる `Death, Harm & Tragedy` は
話題の分類であって、自傷の意図ではないからです。
「サーバーが死んだ」で 0.825 出ることを実測しました。そのため対応づけていません。

**自傷は chakoshi が担当します。** 「死にたい。消えたい。」に対し、
Google は `Violent` を返すだけですが、chakoshi は `self-harm` を返します。
理由コードを `self_harm` として正しく取れるのは今のところ chakoshi だけです。

### chakoshi について

他と違い、**どのカテゴリを有効にするかを管理画面のポリシー設定で決めます。**
えんじいろの方針（性的表現は一律禁止しない、技術用語を弾かない）に
合わせた設定ができるのが利点です。

そのため、返ってくるカテゴリ名をこちらで先に決めきれません。
`_CHAKOSHI_TO_REASON` に無い名前が検出された場合は、**警告を出して無視します。**
知らない名前を勝手に block へ回すと、意図しない拒否になるためです。
警告が出たら、その名前を対応づけへ追加してください。

**ベータ版のため、NTTは本番環境での使用を推奨していません。**
